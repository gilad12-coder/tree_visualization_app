מדריך העלאת נתונים

כך יוצרים מסד נתונים מקומי, מעלים קובץ ובונים ממנו עץ ארגוני ב־be-net ל־Windows. ההוראות מתאימות לגרסה הנוכחית של האפליקציה.

שלבי ההעלאה

הורידו את קובץ הדוגמה, צרו מסד נתונים ותיקייה באפליקציה, ואז העלו את הקובץ

את be-net-reference-upload.xlsx אפשר להוריד מתוך חלון העלאת הקובץ. בדקנו אותו בהעלאה מלאה וקראנו בחזרה את כל שמונה הרשומות.

1לפני שמתחילים

לפני החלפת גרסה, סגרו את כל חלונות האפליקציה. אם נשאר תהליך פתוח, סיימו במנהל המשימות את be-net.exe וגם תהליכים של גרסאות קודמות. רק אז הפעילו את הקובץ החדש.

2יצירת מסד נתונים

בחרו תיקיית Windows קיימת שיש אליה הרשאת כתיבה. האפליקציה תיצור בתוכה קובץ בשם orgchart.db.

3יצירת תיקייה באפליקציה

לאחר פתיחת מסד הנתונים, צרו או בחרו תיקייה בממשק. התיקייה נשמרת בתוך מסד הנתונים, ולכן לא תופיע כתיקייה חדשה ב־Windows.

4העלאת הקובץ

בחרו קובץ .xlsx או .csv, תנו שם לעץ והעלו אותו לתיקייה שנבחרה. בהעלאה הראשונה, השתמשו בקובץ הדוגמה. אחר כך אפשר לשכפל אותו ולהחליף את הנתונים.

חשוב: כשמגדירים מסד נתונים, בוחרים תיקיית Windows קיימת. האפליקציה שומרת בתוכה קובץ בשם orgchart.db. ייתכן שסייר הקבצים יסתיר את הסיומת.

מבנה הקובץ

העתיקו את שמות העמודות בדיוק

שורת הכותרות צריכה להיות השורה הראשונה בגיליון. העתיקו את שמות העמודות כפי שהם מופיעים כאן, כולל האותיות הקטנות והקווים התחתונים. כותרות עם רווחים או קיצורים לא יעבדו.

שם עמודהמשמעות וכללים
hierarchical_structure חובה. נתיב ייחודי שמתחיל ב־/, למשל /1/2.
name חובה. שם האדם או היחידה שיוצגו בעץ.
role חובה. תפקיד האדם או היחידה.
person_id רשות. מזהה חיצוני ייחודי.
department רשות. מחלקה או תחום.
birth_date רשות. תא תאריך של Excel או טקסט בתבנית YYYY-MM-DD.
rank רשות. דרגה או רמה ארגונית.
organization_id רשות. מזהה הארגון.
organization_name רשות. שם הארגון.
personal_information רשות. טקסט חופשי על האדם.
role_information רשות. מידע נוסף על התפקיד.
is_dead רשות. בקובץ הדוגמה מופיע הערך alive.

Excel

  • סיומת .xlsx.
  • הנתונים בגיליון הראשון.
  • אין להוסיף כותרת מסמך או שורות הסבר מעל שורת העמודות.

CSV

  • קידוד UTF-8.
  • השתמשו בפסיק כמפריד, לא בנקודה־פסיק.
תאריכים: בעמודת birth_date השתמשו בתאי תאריך של Excel או בתבנית YYYY-MM-DD. אל תערבבו בין התבניות באותו קובץ.

מבנה הנתיב ההיררכי

  • /1: שורש
  • /1/1: ילד של השורש
  • /1/1/1: נכד
  • /1/1/1/1: דור נוסף
  • כל נתיב חייב להיות ייחודי באותו עץ.
  • יש לכלול בקובץ גם את שורת ההורה.
  • הנתיב חייב להתחיל בתו /.
  • אין לדלג על רמת הורה.
כדי להכין קובץ חדש, שכפלו את קובץ הדוגמה, השאירו את שורת הכותרות ללא שינוי והחליפו רק את שורות הנתונים.

פתרון תקלות

אם ההעלאה נכשלת

can only use .dt accessor...

אם השגיאה מופיעה אחרי החלפת קובץ ההפעלה, כנראה שתהליך מהגרסה הקודמת עדיין מריץ את השרת המקומי.

  1. סגרו את חלון האפליקציה.
  2. במנהל המשימות סיימו את be-net.exe וגם תהליכים של גרסאות קודמות.
  3. הפעילו מחדש את be-net.exe ונסו את קובץ הדוגמה.

Required column(s)... missing

האפליקציה לא מצאה אחת מעמודות החובה.

  • השוו את שמות העמודות לעמוד 2, תו אחר תו.
  • ודאו ששורת הכותרות היא השורה הראשונה.
  • בקובץ CSV ודאו שהמפריד הוא פסיק.

Folder with id ... not found

נבחרה תיקייה ממסד נתונים אחר, או תיקייה שכבר נמחקה. פתחו מחדש את מסד הנתונים הרצוי, צרו או בחרו בו תיקייה, ורק אז העלו את הקובץ.

לא רואים תיקייה חדשה ב־Windows

התיקייה נוצרת בתוך מסד הנתונים. בתיקיית Windows שבחרתם אמור להופיע הקובץ orgchart.db. ייתכן שסייר הקבצים מסתיר סיומות.

בדיקה אחרונה לפני העלאה

  • אין תהליך ישן שרץ ברקע.
  • נבחרה תיקיית Windows קיימת וניתנת לכתיבה.
  • מסד הנתונים הרצוי פתוח.
  • נבחרה תיקייה מתוך מסד הנתונים הפתוח.
  • הכותרות מדויקות ושורת הכותרות ראשונה.
  • כל נתיבי ההיררכיה ייחודיים ומתחילים ב־/.
  • תאריכים הם תאי Excel או YYYY-MM-DD.
  • קובץ CSV הוא UTF-8 ומופרד בפסיקים.
אם קובץ אחר לא נטען, נסו תחילה את be-net-reference-upload.xlsx.
